## Code Examples

### Codewars — Remove Spaces

```javascript
function noSpace(x) {
  let result = '';

  for (let i = 0; i < x.length; i++) {
    if (x[i] !== ' ') {
      result += x[i];
    }
  }

  return result;
}
```
